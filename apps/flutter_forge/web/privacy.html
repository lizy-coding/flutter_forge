适用范围
本说明适用于 Flutter Forge 联网完整版的 Windows、macOS、Web 与 Android 构建，不代表这些构建均已在商店上架。应用提供编程教学与交互实验，没有开发者运营的用户账号、广告、统计分析或自动云同步服务。教学中的模拟账号和文章不是真实用户账号。Android 离线发行包使用单独的离线版政策。

本地保存与处理的数据
应用在用户私有存储中保存主题、最近访问的模块入口，以及你配置的模型服务端点和模型名称。部分教学模块会保存你主动输入的本地演示内容。文件、字体或设备信息仅在相应实验中按需处理，不因选择文件就自动上传全部文件或扫描磁盘。WebView2 可在用户可写目录保存网页缓存、Cookie 和站点数据；访问的站点可能按自身规则处理这些数据。
联网模块载入网页、视频或请求服务时，相应服务通常会收到 IP 地址、请求时间、请求头和资源地址，并按其自身政策处理这些访问数据。

模型服务与第三方工作流
固定教学回放不需要模型服务。当你配置真实模型并主动生成时，问题文本、当前实验状态、组件目录及必要上下文会发送到你选择的服务端点；临时令牌随请求用于认证。连接本机桥接时，请求可由你另行启动的桥接程序转发到其配置的模型服务，相关 CLI 登录由该程序管理。
连接远程工作流 Hub 后，模块会向该 Hub 请求任务信息，并在你操作时发送工作流定义、任务输入和执行结果。应用不替你决定第三方服务的数据保留期限、处理地区或是否用于训练；使用前请查看所选服务的隐私政策与配置。请勿在教学输入中填写不必要的个人敏感信息。

凭据与传输
模型连接的临时令牌和 Hub 令牌用于当前模块会话，不写入模型连接的偏好设置，也不作为最近访问记录保存。端点与模型名会被记住。远程模型及 Hub 端点要求 HTTPS；仅本机开发桥接允许 localhost/回环地址使用 HTTP。临时令牌并非开发者提供的账号，应用不会主动索取你的服务登录密码。
请求内容会被接收该请求的服务处理；关闭本应用不等于删除服务端已经接收的数据。诊断日志、系统崩溃报告和你主动提交的截图可能包含路径、端点、错误或实验内容，反馈前请去除令牌与不必要的个人信息。

按需使用的系统与设备能力
文件选择、设备和电池信息、蓝牙、USB、通知、生物识别及图形能力仅用于相应教学模块，实际可用性取决于平台、系统权限和硬件。生物识别由系统验证，应用只接收验证结果，不读取或保存指纹、人脸模板。可拒绝可选权限、停止设备实验或在系统设置中撤销授权。教学通知在本机产生，不作为广告推送。

控制、保留与删除
你可选择教学回放，取消正在生成的请求、断开连接或离开模块，停止后续模型或工作流操作。可通过系统提供的应用重置功能（可用时）、卸载应用或浏览器站点数据设置清理相应的应用私有数据。卸载不会删除你原有的导入文件，也不会自动删除第三方模型、网页或 Hub 已接收的数据；这些数据需按服务方提供的方式管理或申请删除。
macOS 上卸载应用不保证清除全部偏好及网页数据，需按对应存储方式管理。
可在“关于 → 隐私与数据”中清除最近访问的模块入口，不影响主题、实验内容与原有文件。

未成年人及说明变更
本应用面向编程学习者，不以儿童为目标群体，不主动要求填写姓名、证件或支付信息。新增数据处理目的或能力时会更新本说明，并在需要时重新说明和征求选择。

使用第三方服务前，请确认其年龄要求和隐私规则。

联系与反馈
应用不自动向开发者上传测试报告、诊断日志或实验文件。主动反馈时，请去除令牌、私钥、账号密码与不必要的个人信息。收到的反馈仅用于排查和回复。复制邮箱仅写入系统剪贴板，由你自行决定是否发送邮件。

平台差异
Windows：内嵌网页使用 WebView2 时，可在用户可写目录保存缓存、Cookie 和站点数据。系统应用重置是否可用取决于安装方式。
macOS：设备实验受系统权限及硬件限制；应用私有偏好与内嵌网页数据依各自存储规则管理，卸载应用不保证清除全部偏好及网页数据。
Web：偏好保存在浏览器站点存储中，可通过浏览器清除站点数据；文件选择只处理用户主动选择的内容。网页及媒体服务会处理相应访问请求。浏览器能力与原生应用不同。
Android 联网构建：联网模块会访问相应服务；设备权限可在系统设置中撤销，应用私有数据可通过系统应用设置清除。是否分发以渠道登记为准。
