# USB 网络连接基础

入口 `/usb-network`，Windows/macOS。教学页面独立使用 workspace 内 `usb_network_bridge`，不依赖 xstudio_framework 或其它学习模块。

## 基本流程

1. 插入支持 CDC-NCM 的设备，确认系统网络接口已具备 IPv4。
2. 点击「扫描 NCM 网卡」，选择接口；手动填写设备 USB 网络 IPv4 和 TCP 服务端口。
3. 点击「连接」，发送 UTF-8 文本；按测试服务需要选择追加换行。
4. 观察接收字节与十六进制日志，断开；拔线后手动扫描和重新连接。

真实验证需要设备提供原始 TCP 服务，例如已授权部署的回显服务。端口 9001 只是可编辑初值；xstudio 的设备 WebSocket 服务需要握手和设备协议，不能用 hello 直接验证。页面不虚构设备地址或成功响应。

## 边界

无自动发现、双路切换、自动重连、文件传输、HLS、专有加密或驱动安装。日志最多 100 条，单次发送最多 4096 字节，接收预览最多 512 字节。TCP 块不代表完整消息，文本仅用于观察；实际协议应独立实现。

页面拥有会话及连接；退出时释放，晚到的连接结果关闭，晚到回调不更新界面。平台目录与稳定路由由共用能力规则生成。模块初始学习质量状态为 pending；平台验收独立记录，入口支持不代表实际收发已通过。
