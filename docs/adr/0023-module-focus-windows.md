# ADR 0023：以模块为桌面专注窗口的导航根

状态：已接受。模块专注窗口已接入工作树，真实宿主验收待执行。

桌面独立学习窗口以单个模块为根，承载该模块及其下级教学和实验页面。模块专注窗口用模块名和本地导航体现窗口身份，返回止于模块根。此决策更新 ADR 0005 和 ADR 0016 中关于专注窗口承载范围的约定。

主窗口拥有全局导航和专注窗口管理权，可以查看、聚焦和关闭专注窗口。关闭主窗口结束应用，关闭专注窗口只关闭该窗口。每个专注窗口保有自己的导航和实验页面状态，并跟随应用主题与语言。聚焦主窗口保留其原有路由。

## 打开与导航

- 主窗口的模块入口和模块页提供「在专注窗口打开」。从模块入口打开时进入模块根，从模块页打开时保留当前可直达的模块子页。打开后主窗口保留当前位置，专注窗口标题显示模块名。
- 每个模块最多有一个专注窗口。重复打开时聚焦已有窗口，并保留其当前子页和实验状态。
- 本地返回止于模块根。指向工作台或其他模块的链接显式标明「在主窗口打开」，由主窗口处理导航。「聚焦主窗口」只切换焦点并保留主窗口路由。
- 打开失败时，主窗口保留当前教学页并允许重试。

## 迁移边界

迁移基线从分类页创建分类专注窗口，按分类复用。模块专注窗口从模块入口或模块页创建，主窗口集中显示已打开的专注窗口，并提供逐个聚焦和关闭的操作。

沿用 ADR 0005 的准入条件。主窗口位于受支持的桌面宿主、宽度至少为 600dp 且运行时多窗口能力可用时，才提供显式打开入口。普通分类与模块点击继续使用当前窗口内导航。复用以稳定模块标识为准，同分类的两个模块可以分别打开。首次传入的子页须属于目标模块且可直达，否则进入模块根。

## 实施与验收顺序

1. 在 macOS 现有分类窗口链路上定位回归。记录构建与引擎版本、入口可见性、点击是否发出创建请求、原生窗口是否创建、子引擎后端、Dart 就绪握手和首屏是否显示。检查隐藏启动及语言同步失败对就绪信号的影响。使用同版本的 Impeller 开关对照验证，归因以复现结果为准。
2. 迁移到模块专注窗口。验证从模块入口和子页打开、同分类双模块并存、重复打开保留实验状态、返回止于模块根、跨模块链接显式交给主窗口，以及仅聚焦主窗口时保留原路由。验证主窗口管理入口可以查看、聚焦和关闭指定窗口，关闭主窗口结束应用，创建失败后可重试。
3. 分别在真实 macOS 和 Windows 宿主验收。当前 macOS 回归基线为 Flutter 3.50.0 与 Impeller 开启；Windows 遵循 ADR 0021 的系统标准窗框，并独立验证同一导航与生命周期契约。按宿主记录构建和实际操作结果。
