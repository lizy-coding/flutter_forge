# ADR 0020: NFC 学习以卡片发现与碰卡唤起为边界

状态：accepted（产品范围）；实现与真机验收尚未执行。

用户希望通过 iQOO 手机和现有实体卡片理解 NFC 工作方式，并选择应用外碰卡进入 Forge、发现卡片即算识别成功的首期方向。首期限定 Android，分别建设前台卡片发现和系统分发进入学习页两条路径；测试对象先用现有支持非接触式通信的实体银行卡。发现只表示系统提供了技术信息，不要求存在 NDEF，也不把射频标识解释为银行卡号或永久身份。

采用这一边界，是因为前台 Reader Mode 能支持发现过程的观察，却不能替代应用外唤起；系统分发又受标签内容、技术匹配、用户设置及设备行为影响。两项验收分别记录，避免用前台扫描通过代替碰卡唤起通过。支持任意银行卡、银行卡业务协议、写卡、复制卡及手机卡模拟均超出首期。银行卡录入手机钱包不作为 Forge 可读取实体卡或钱包数据的证据。

平台接入沿用 [ADR 0019](0019-platform-capability-bridge-packages.md)，无需新增跨能力抽象。具体实施与 Agent Hub 托管边界见 [NFC 学习实施方案](../NFC_LEARNING_PLAN.md)。
