# 通用桌面工作台与沉浸式标题栏

状态：accepted，2026-10-17 用户确认；材质范围、默认外观和移动端阶段安排由 [ADR 0018](0018-platform-interaction-and-native-materials.md) 取代，其余窗口与工作台约定继续有效。

macOS 与 Windows 共用 Flutter 工作台内容和约 48dp 的沉浸式顶部导航，但窗口操作遵循平台规范：macOS 保留左侧原生红黄绿按钮，Windows 保留右侧原生最小化、最大化／还原与关闭按钮及系统 Snap 行为。宿主报告按钮所需逻辑留白，Flutter 不重画系统窗口按钮；导航、当前位置、主页、快速打开和主题入口共享内容背景。这样既统一学习体验，也保留平台熟悉的窗口操作。原有独立 AppKit 导航工具栏停止使用，系统菜单作为等价命令入口保留。

标题栏主页按钮进入当前窗口根路由；空白区双击遵循平台系统习惯，macOS 尊重双击偏好，Windows 最大化／还原。真实全屏通过独立按钮或 F11 进入／退出；macOS 使用系统全屏，Windows 使用当前显示器全区域并保存、恢复窗口位置及原最大化状态。禁止将原生最大化按钮重定义为全屏。原生窗口能力需要各主机分别验证。

主窗口以学习工作台为默认入口，提供最近访问、分类目录和最多“分类 → 模块”两层侧栏；单个当前模块通过稳定路由切换，不建立多标签或后台模块保活。返回通过窗口内访问历史恢复位置，最近访问只记录模块入口，不承诺恢复实验任务。快速打开匹配标题、分类及概念关键词，支持键盘选择和退出，并保留当前界面上下文。作者资料保留在关于入口。

默认采用中性实色、跟随系统明暗；透明主题作为完整外观保留，首期覆盖标题栏、导航、工作台、目录和快速打开，在应用自己的背景上呈现通透层次。透出桌面与其他窗口不属于本期。高对比度使用实色表面，减少动态效果时不启用持续装饰动效，主题切换不重建路由。

主窗口关闭时退出应用并关闭分类专注窗口；分类窗口关闭只影响自身。分类窗口复用同一标题栏与分类内导航，不呈现其他分类。移动端下一阶段单独评估，本期保持其现有入口与教学页面；模块内部教学布局和实验工作台面板安排到下一期。

本决策取代 ADR 0015 的内容区平台专属外观、AppKit 导航工具栏和禁止整体透明的约定，以及 ADR 0012 中创作者默认首页、侧栏不含模块、仅标题搜索的约定。稳定路由、模块支持判定、显式打开分类窗口和既有生命周期边界继续有效。macOS 实机操作、Windows 构建与真实主机操作分别记录，不以一端结果代表另一端验收。
