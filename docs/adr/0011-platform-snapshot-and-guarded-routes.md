# ADR 0011: 平台快照与守卫路由

状态：accepted

Flutter Forge 在进程启动时建立不可变宿主平台快照，平台判定模型仅覆盖 Android、iOS、macOS、Web 和 Windows。模块以 `excludedPlatforms` 声明限制，目标集合内未排除即支持，目标外平台一律不支持；所有模块路径保持注册，不支持的平台进入统一说明页而不是业务页面或 404。窗口尺寸与设备能力不进入快照，平台验收也不形成额外运行时状态，以保持路由稳定并降低普通模块的声明维护成本。

## 后果

- Router、目录和导航策略共享同一启动快照，不再分别读取全局平台变量。
- 平台类模块必须显式确认排除集合，普通模块可以省略空集合。
- 权限、USB、GPU、文件提供器和插件运行结果由模块适配器处理，不动态增删路由。
- ADR 0003 的“不支持模块不注册路由”和支持列表表达方式被本决策取代；学习质量状态仍与平台支持分离。
