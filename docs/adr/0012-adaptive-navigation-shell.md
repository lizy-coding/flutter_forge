# 自适应导航外壳与分类专注窗口

状态：accepted

Flutter Forge 在所有平台共享“创作者主页—学习分类—业务模块”的信息架构，但按可用宽度选择导航外壳：小于 `600dp` 使用按需打开的移动导航，`600–1023dp` 使用 NavigationRail，`1024dp` 起使用可折叠侧栏。macOS 和 Windows 主窗口及分类专注窗口的最小尺寸为 `800 × 600`，避免原生桌面窗口退化到未经设计的紧凑状态。

主窗口负责发现、标题搜索和应用内学习导航；桌面多窗口不再是打开分类的默认行为，而是使用者显式选择的增强能力。分类专注窗口只承载一个分类、复用同分类已有窗口且不重复主窗口侧栏。移动端保持单窗口，使用 Drawer、首页分类入口和全屏教学页。

默认路由为创作者主页，只展示作者身份与 GitHub 直链；学习分类和项目内容由导航外壳承载，不在主页重复推荐，也不再建立独立“关于”页面。初版搜索只匹配模块标题，侧栏折叠偏好只在当前运行期间保留。

本决策取代 ADR 0005 中“桌面宽窗口打开分类时默认创建独立窗口”的交互；ADR 0005 的移动端单窗口、紧凑窗口应用内导航和多窗口生命周期边界继续有效。
