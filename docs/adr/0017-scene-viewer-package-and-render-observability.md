# 内部 3D 查看包与可观测绘制

状态：accepted。日期：2026-10-17。用户批准先抽离内部包，再实施 P0 绘制观测与控制。

`packages/forge_scene_viewer` 集中维护固定版本 Flutter Scene 的适配、相机、选择、调度及诊断。Forge 教学模块持有示例部件、教学内容和路由；平台入口与 Android 只读策略继续由应用能力契约决定。当前先使用 Pub workspace，与应用一同验证；出现实际外部调用方和稳定公共 API 后再评估独立仓库与发布节奏。ADR 0008 的上游 API 隔离职责由模块内边界迁移至内部包，其他平台证据边界继续生效。

绘制采用上游公开的 `Scene.render` 接口，在内部包内提供稳定的渲染视图与实际调用采集点，以支持按需、持续、手动单帧模式。自管帧驱动承担可见性、运动时间基准和退出清理；后续依赖 SceneView 自动语义或其他能力时须明确补齐。诊断与场景绘制分别隔离，诊断刷新不能成为场景持续重绘的原因。

调度请求、实际渲染调用、正常返回、Flutter 窗口帧耗时以及 GPU 完成是不同事实。P0 的 CPU 统计、调用频率和单帧 Pass 抓取不代表 GPU 耗时或屏幕首帧；未采集的 GPU 指标显示为空。采样采用有界窗口，主动抓取不采图片并单独标记，生命周期退出释放本包资源。
