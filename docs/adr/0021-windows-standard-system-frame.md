# Windows 系统标准边框与内容区工具栏

状态：accepted，2026-11-02 用户批准；取代 ADR 0016/0018 的 Windows 沉浸式标题栏与默认 Mica 约定。当前实现与 Windows 构建、真机验收分开记录。

第二轮 Windows 1.2.14 测试在已安装与解包 EXE 中均出现还原点击命中客户区、实际状态不变的现象。现有证据不能确认最终根因，但自定义边框、DWM 按钮区域与 Flutter 视图裁剪的协调已持续阻碍核心功能验证。决定让 Windows 主窗口和分类窗口默认使用系统标准标题栏、边框与窗口按钮，Flutter 仅保留内容区的导航工具栏；不再以沉浸式外观一致性作为基础窗口功能交付前提。

Windows 退出自定义非客户区尺寸计算、边框命中、DWM 客户区扩展及 Flutter 视图裁剪，窗口使用实色兼容背景，停用 Mica。用户已有主题偏好继续保存，macOS 原生材质保持现有行为。内容区工具栏保留主页、返回、搜索、主题及独立全屏入口，不再拖窗、双击最大化，也不为系统按钮预留空白。

窗口拖动、双击、最小化、最大化／还原、关闭和 Snap 交由系统；F11 与全屏按钮继续切换真实全屏并恢复原位置及最大化状态。主窗口关闭退出应用、分类窗口关闭仅影响自身。共享教学内容、导航与多窗口生命周期继续复用。

不自动探测点击失败后切换边框，也不改用 Flutter 自绘窗口按钮。后续如恢复增强外观，须单独取得主／分类窗口、DPI、RDP、全屏恢复与无障碍证据。当前改动不能提前标为 Windows 真机通过。
