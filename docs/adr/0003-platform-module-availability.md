# ADR 0003: 平台模块可用性

| 属性 | 值 |
|------|-----|
| 状态 | accepted |
| 日期 | 2026-08-25 |
| 决策者 | forest |

## 决策

1. `ModuleEntry.supportedPlatforms == null` 表示模块默认支持所有平台。
2. 平台相关模块显式声明支持的平台集合。
3. 平台判定由模块注册表统一执行，不由模块页面直接调用平台 API。
4. 不支持的模块保留在目录中并显示不可用状态；其模块路由不注册。
5. 学习质量状态（`pending/ready/recommended`）与平台可用性分离。

## 范围

第一阶段按 `TargetPlatform` 隔离，不引入独立能力矩阵或动态插件系统。
