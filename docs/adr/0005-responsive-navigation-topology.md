# ADR 0005: 移动端单窗口与桌面响应式导航

| 属性 | 值 |
|------|-----|
| 状态 | accepted |
| 日期 | 2026-08-26 |
| 决策者 | forest |

## 决策

1. Android、iOS 和 Web 使用应用内分类导航，不创建业务多窗口。
2. 小于 `600dp` 的紧凑窗口使用应用内导航。
3. 只有桌面平台、窗口宽度不小于 `600dp` 且多窗口能力可用时，才创建分类窗口。
4. `NavigationPolicy` 负责决定导航拓扑；`MultiWindowManager` 只负责桌面窗口生命周期。

## 后果

- 移动端不依赖 `desktop_multi_window` 才能完成分类学习流程。
- 桌面窄窗口可以回退到应用内导航，避免小窗口多 Engine 黑屏和布局拥挤。
- 桌面多窗口之间不共享可变业务状态；分类窗口只承载自己的教学页面。
