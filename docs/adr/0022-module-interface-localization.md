# 官方本地化基础与框架目录双语

状态：accepted，2026-11-06修订。取代本ADR先前要求35模块操作界面当期全部双语的范围；模块内部统一中文的语言边界已确认，收尾代码已接入，源码验证与真实平台验收分别记录。

Flutter Forge保留官方flutter_localizations、gen_l10n、ARB及独立可复用forge_localization包，当期完成框架与目录双语，教学实验保留中文并明确标注。用户重新评估收益后，将全模块操作翻译改为未来按实际需求推进，以降低每次实验演进的双语维护与布局验收成本。旧全模块方案保留历史记录，不再作为当期发布阻塞条件。

URL、路由ID和存储键稳定；语言入口、默认跟随系统、手动选择持久化、即时切换保留状态和双语检索沿用既有决定。Android仍为此次发行的真机关口；框架收尾及新候选包验收完成后安排发布，不承诺日期或其他平台已验收。

窄布局继续仅对按钮、标签页和表头使用人工短标签，保留完整语义和提示；不另建各语言布局。模块内部标题、操作按钮、公共章节和正文统一中文；框架导航/返回跟随界面语言。入口与实验页标注“中文实验”，以后按完整模块选择是否升级双语。

详细边界、成本与验收见[框架与目录国际化收尾方案](../LOCALIZATION_PLAN.md)。
