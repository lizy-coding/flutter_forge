# macOS 基础桌面外壳

状态：accepted

macOS 以 Finder／系统设置式的桌面工具体验为方向，采用少量 AppKit 宿主接入与 Flutter 内容组合：保留根 FlutterViewController、GoRouter 和模块边界，由系统承担普通窗口材质、工具栏与菜单，Flutter 提供紧凑侧栏、目录和教学内容。这样可复用主窗口与分类窗口的生命周期，而无需重写原生导航控制器。

首轮只完成基本架子与常规系统接入，主导航使用克制选中反馈，内容区采用实色背景；保留 macOS 12 下限，不要求新版 Liquid Glass API。其他平台保持原有呈现，各教学 Demo 保留演示用途。真实材质合成、焦点、窗口失活与多窗口重开必须在实现后分别确认。

标题栏和工具栏使用系统普通底色与分隔线，保证按钮可辨识和拖拽操作稳定；仅侧栏区域允许使用基础材质，不采用整窗透明方案。
