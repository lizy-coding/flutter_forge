## 教学范围

新增基础机制模块「绘制入门：从画形状到算颜色」，稳定路由 `/pixel-shader-intro`，难度为入门，预计 15 分钟。

只使用「左半边涂蓝」这个实验，按三步逐渐显示操作：

1. 宽 200、高 100 的画布，直接画一个宽 100 的蓝色矩形。
2. 改成对每个位置判断 `x < 100`，输出蓝色或白色；切换描述方式，比较相同的蓝色范围。
3. 加宽到 400，固定 100 只占四分之一；改用 `U = x / width` 和 `U < 0.5`，重新得到左半边。`V = y / height` 表示纵向比例。

支持点击、拖动、左右位置预设、描述方式切换、画布宽度及规则切换、上一/下一步、复位本步和重新学习。换步或复位会回到步骤开头。选中位置取整数教学单位，比例保留完整读数，避免颜色判定与舍入显示矛盾。

本页使用 Dart/Canvas 和放大采样网格解释颜色规则，不执行真实片元 Shader。UV 是描述位置的比例，Canvas 也可以使用它；不将两种描述方式等同于 CPU/GPU 性能差异。真实 GLSL、纹理、颜色渐变等内容留给后续课程。
