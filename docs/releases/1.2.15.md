# Flutter Forge 1.2.15

Android 隐私告知修复版本。

- 首次启动明确告知个人信息处理规则，支持离线阅读完整政策。
- 只有明确同意且保存成功后才进入应用；拒绝或返回不记录同意。
- 按政策版本保留选择，政策更新后重新告知。
- 补充蓝牙、旧 Android 定位、通知、生物识别、文件与媒体组件权限用途及拒绝影响。
- 披露蓝牙外设地址与服务 UUID 的本地缓存、保存期限及删除方式，增加关于页权限用途速览。

离线政策版本：`offline-2026-11-13.1`。公开页面与最终安装包必须核对一致。

1.2.14 / 4015 的指定 Android 真机验收见本地记录；1.2.15 / 4016 按最终包补验，不复用候选版本冒称通过。
