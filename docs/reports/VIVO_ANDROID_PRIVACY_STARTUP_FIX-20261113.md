# vivo Android 首次启动隐私告知修复

4013（1.2.14）于 2026-11-13 被内容审核驳回。后台原因为首次启动未通过明显且易于访问的弹窗提供隐私声明。举证设备为 vivo X300。

用户提供的《Flutter Forgev1.2.14基础测试报告20261113141101.pdf》不是驳回原因报告：18 台设备基础兼容性及静态扫描通过。报告内 APK MD5 为 `813b41220040a6150b4b5db98569ef2a`，与原 4013 安装包相符。实际驳回证据保存在 `.release/vivo/1.2.14/rejection-20261113/`；渠道台账追加 rejected 观察，保留此前提交成功记录。

## 修复行为

Android 在创建应用路由、最近访问和演示内容之前展示隐私告知。弹窗以中英文提供数据处理摘要、可选权限用途、完整政策入口及明确同意／拒绝操作。完整政策复用当前发行版随包政策，可在未同意时离线查看，并显式关闭返回。

仅明确点击同意且保存成功后启动应用。按发行版政策版本保存选择；没有记录的旧用户升级后同样需要告知，政策版本变化时重新告知。拒绝或系统返回退出，不保存同意；保存失败停留并提示重试。桌面和 Web 启动流程保持现有行为。
