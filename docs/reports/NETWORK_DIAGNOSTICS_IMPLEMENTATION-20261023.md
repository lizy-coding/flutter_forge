## 实现

入口：网络与平台 → 网络诊断：从现象到检测证据；稳定路由 `/network-diagnostics`。

用户选择现象、编辑最多四个目标并主动开始检测；会话先读取操作系统与网卡地址，再分阶段执行 DNS、TCP 与 HTTP(S) HEAD。检测结果按目标与轮次更新，固定 UI 呈现基本结论，展开后显示阶段耗时、地址与响应状态。快速模式一轮，观察模式五轮；阶段超时三秒，会话上限 60 秒，支持取消、重新检测和离开页面时释放连接。

报告仅保留当前页面会话，预览默认隐藏目标、网卡名称、本机与解析地址，复制内容与预览一致。HTTP 错误状态与网络失败分开表达，全部目标失败不能证明整体断网；未完成样本不计作失败。未增加依赖、AI／GenUI、带宽测速、系统设置修改、局域网设备发现或历史持久化。

平台入口声明由生成器的桌面网络诊断适配规则推导。macOS、Windows 开放；Android、iOS 后续适配，Web 不做，均保留稳定不可用路由。学习状态保持 pending，不与平台支持或测试通过混用。
