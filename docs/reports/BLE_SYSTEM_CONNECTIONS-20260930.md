# BLE 系统开关与连接列表验收 — 2026-09-30

## 改动

- Android 关闭状态显示系统确认开启按钮，先请求并核对蓝牙权限。
- Android 开启状态提供“关闭蓝牙（系统设置）”；使用公开的系统设置 Intent，由用户操作开关。返回页面后刷新状态与连接列表。
- 页面头部同时展示应用 GATT 连接、系统 GATT 连接以及 Android 音频/通话连接；音频、通话、助听器和 LE Audio 查询按标识去重。
- 系统连接查询不依赖扫描列表或 `isSystemDevice` 标记，进入页面时已有权限即自动查询，支持已有应用连接时刷新，刷新替换旧列表。
- 系统连接不是本应用 GATT 连接；仅系统 GATT 条目提供“连接 GATT”，音频条目不开放 GATT 操作。
- 蓝牙关闭时清理连接和扫描状态；离开页面后的异步系统查询不再更新已释放的页面。

## 平台边界

Android 13 起普通应用不能使用 `BluetoothAdapter.enable()/disable()` 直接修改开关。开启使用系统确认请求，关闭使用 `Settings.ACTION_BLUETOOTH_SETTINGS`。

公开查询覆盖 GATT 与音频 Profile。不会用已配对列表推断已连接；HID 等连接可能无法从这些接口列出，页面提供“查看完整系统连接列表”进入系统设置。

## 人工验收步骤

1. 允许 USB 安装并安装改版 APK；授予附近设备权限。
2. 系统连接一台音频外设，进入 BLE 页，保存头部设备名和连接类型截图；与系统设置的实际连接核对。
3. 刷新、开始扫描、搜索时，系统连接保持在头部且不重复出现在附近广播列表。
4. 在应用建立 GATT 连接时刷新系统连接，确认当前 GATT 状态与断开操作仍保留。
5. 点击“关闭蓝牙（系统设置）”进入系统设置，由用户关闭；返回页面应显示已关闭且连接清空。
6. 点击系统确认开启，分别验证同意和取消；确认权限拒绝、状态更新及再次返回页面没有残留连接。
7. 对手表等 HID 连接，确认列表提示和系统设置入口，不将已配对设备误报为已连接。
