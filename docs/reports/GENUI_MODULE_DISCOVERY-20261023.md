# GenUI 模块探索接入记录

范围：当前未提交工作区。2026-10-24 完成代理修复与真实 macOS 流程重验。不是发布版本或其他平台的真实操作验收。

## 已交付

桌面与紧凑首页接入学习意图输入、模型配置、推荐结果与澄清操作。模型通过受限 Catalog 选择分组、对比、真实模块卡片和澄清选项；卡片标题、简介、难度与入口来自本地模块注册表。澄清经 SDK 回传状态并更新界面，点击模块由本地 GoRouter 进入现有页面，不再次调用模型。

探索输入与推荐卡片复用现有玻璃主题；聚焦／悬停提供边缘提亮与轻微柔光，提交按钮融入输入区，配置入口收纳到右上角。实色、高对比度和减少动画偏好保持有效，不新增玻璃插件。示例只填入问题，不自动消耗模型调用。桌面主页移除重复大标题与重复主按钮，限制内容宽度，保留本地浏览及既有窗口／侧栏。

shared/genui 提供共享模型传输与临时连接表单，应用层不依赖学习叶子模块。模型输出经模块与组件白名单校验，非法响应保留原有结果。未增加知识库、后台工作流、多会话或滚动知识展厅。

## 真实流程验收

`integration_test/module_discovery_live_test.dart` 在 macOS 原生 Debug 引擎中连接本机 Codex CLI 桥接完成：

1. 提交“异步任务为什么会卡界面”的学习意图，收到真实模块推荐及澄清选项。
2. 触发生成的澄清按钮，经 SDK 事件回传完成第二次真实生成。
3. 点击生成卡片，通过 GoRouter 实际进入 `/isolate-basic`；主页输入组件退出，模块存在于真实注册表。
4. 模型请求总数保持 2，模块进入未新增请求。输出标记：`DISCOVERY_LIVE_PASS requests=2 opened=/isolate-basic components=5`。

两次 CLI 调用分别耗时约 42.1 秒与 28.1 秒；这是本机桥接与当前网络的一次记录，不是响应时延保证。桥接先等待 CLI 最终输出再分块交付，尚非逐 token 流；当前仍有明显等待，页面提供状态反馈与取消。

此前两个 90 秒请求超时已定位到代理未继承：同样的最小请求直接连接超时，补入系统已有代理后返回成功。桥接现在只向 CLI 子进程补充系统 HTTP(S) 代理，保留显式环境变量优先级，不修改全局配置、不记录代理凭据。

## 使用

主页右上角调节按钮配置模型。沿用现有桥接：

```bash
python3 tool/genui_codex_bridge.py --token-file /tmp/forge-genui-home.token
```

端点 `http://127.0.0.1:8766/v1/chat/completions`，模型 `codex-default`，临时令牌为指定文件内容。使用当前 CLI 登录与可用额度，无需另配 API key。配置只保留在当前页面内存，离开后需要重新配置。服务不可用时可继续使用本地浏览。

本次验证进程目前使用 `/tmp/forge-discovery-verified.token`，仅监听回环地址；若继续沿用该进程，无需重复启动。临时定义文件不得提交。客户端取消会停止等待并隔离迟到结果，已启动 CLI 仍可能运行到结束或上限，期间桥接返回忙碌状态。
