# 桌面主框架第一阶段总结

日期：2026-10-17。设计决策见 [ADR 0016](adr/0016-shared-desktop-workbench.md)。

本阶段完成桌面主框架实现，用户确认 macOS 手工验收通过；Windows 已接入对应宿主源码，构建和真实主机操作仍待独立验证。当前交付为 `dev` 分支上基于 `6910044320f33ae27aa32d8ff5e2617672ccb248` 的未提交工作区，不代表已发布版本。

## 最终设计与交付

- 工作台内容共用 Flutter 渲染，窗口控制遵循平台规范：macOS 左侧原生红黄绿按钮，Windows 右侧原生窗口按钮，保留系统最大化及 Snap 命中处理。
- 顶部沉浸式导航约 48dp，包含侧栏切换、返回、主页、当前位置、快速打开、外观和独立全屏入口。主页进入当前窗口根路由；分类专注窗口返回本分类主页。
- 标题栏空白区支持拖拽；双击使用系统行为，macOS 尊重双击偏好，Windows 最大化／还原。独立按钮和 F11 切换真实全屏，Windows 全屏退出时恢复此前窗口位置和最大化状态。
- 侧栏支持分类／模块两层导航及宽度调整。单个当前模块通过稳定路由切换，不增加标签页和后台模块保活。
- 工作台首页提供最近访问和分类入口；最近访问持久化最多八个模块入口，不代表实验恢复或学习进度。作者资料保留在关于入口。
- 快速打开保留页面上下文，匹配标题、说明、分类和概念，支持键盘选择、确认和退出。
- 桌面首次启动默认中性实色并跟随系统明暗，保留用户已保存的主题选择。透明主题覆盖主框架，透出应用自身背景；高对比度使用实色。主题切换保留路由。
- 主窗口关闭退出应用，分类窗口关闭仅影响自身；分类窗口复用同款框架并限定分类范围。

## 边界与归属

应用层 `DesktopWorkbenchShell` 负责布局和导航，`DesktopWindowHost` 负责每引擎的窗口命令、状态与原生按钮留白。macOS 和 Windows runner 提供宿主实现，不修改工作区多窗口包的现有未提交实现。路由、平台守卫和模块元数据继续由生成源与 `module_registry` 统一维护。

本期没有改造模块内部教学布局，没有交付桌面背景透视或移动端重新设计。移动端保留原有入口；Web／移动端的自动化回归不等同真实平台验收。
